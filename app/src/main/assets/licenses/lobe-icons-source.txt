All files are unmodified 640 x 640 PNG assets from this published package.
Every SHA-256 was checked against the package metadata integrity values.
Color variants are used wherever supplied for these providers: Antigravity,
Devin, Claude, MiniMax, AIHubMix, and DeepSeek. OpenAI, Cursor, OpenCode, and
GitHub Copilot use their standard monochrome icons; this version has no
separate Color asset for them. Light assets are used with a white tile for
monochrome glyphs so they remain visible in both app themes.
OpenCode Zen and OpenCode Go share the official OpenCode icon.
